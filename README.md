# ziko_lecolo
Jeu de plateau

**Ziko l'écolo** est un jeu de plateau en 2D. Ziko, 10 ans, a 40 ans pour repousser la date de fin de
la vie sur Terre et améliorer la vie de tous les êtres vivants. Une partie dure environ 20 à 25 minutes.

📘 La conception complète du jeu est dans le dossier [`docs/`](docs/README.md).

Pour lancer le jeu en local depuis VS Code, choisis **Terminal → Exécuter la tâche… → Ziko : lancer le site en local**. Le navigateur s’ouvre automatiquement. Pour arrêter le serveur, appuie sur `Ctrl+C` dans le terminal de la tâche.

Le watcher Vite ignore le cache Visual Studio (`.vs/`) pour éviter les erreurs `EBUSY` sur les index `.vsidx` verrouillés. Si un serveur est déjà lancé lors d'une modification de cette configuration, redémarre la tâche.
